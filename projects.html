  • Drink builder for a fictional shop: pick tea, milk, sugar, ice and toppings while an SVG cup changes colour live, pearls drop in one by one and the price updates.虚构奶茶店的调饮器：选茶底、奶、甜度、冰量和小料，SVG 杯子实时变色，珍珠一颗颗掉进去，价格同步更新。

DeployGuard CLIDeployGuard 命令行工具

Fault-tolerant deployment with automatic rollback带自动回滚的容错部署工具
20262026 年
deploy-cli

      
Replayed from a real run: v2.0 fails its health check, so DeployGuard rolls back to v1.0.回放自一次真实运行：v2.0 没通过健康检查，DeployGuard 自动回滚到 v1.0。

    

    
  • C++ CLI that runs and watches deployment scripts, catching a non-zero exit code or crash the moment it happens.用 C++ 写的命令行工具，运行并监控部署脚本，一旦出现非零退出码或崩溃立刻发现。
  • On failure it stops the deployment and runs a recovery script to restore the last known-good state.部署失败时自动中止，并运行恢复脚本回到上一个正常状态。
  • YAML config keeps orchestration separate from the scripts, so rollback behaviour changes without recompiling. Unit-tested with doctest and checked in CI.YAML 配置把编排逻辑和执行脚本分开，改回滚行为不用重新编译。用 doctest 做单元测试，并接入 CI。

    
Why I made it为什么做
At Sioux I saw how much damage a half-finished install does. I wanted a small, general tool that never leaves a machine in that state.在 Sioux 实习时见过装到一半的安装会造成多大麻烦，所以想做一个通用的小工具，保证机器永远不会停在那种状态。
Hardest part最难的地方
Surviving a crash mid-deploy. Backups live on the same persistent disk as the app, not in /tmp, and the tool checks for an unfinished deploy every time it starts.部署中途断电或崩溃怎么办。备份放在和应用同一块持久磁盘上，而不是会被清空的 /tmp；每次启动时还会先检查有没有没做完的部署。
What I learned学到了什么
Treating deployment as a state machine makes failure handling something you design, not something you patch later.把部署当成状态机来写，失败处理就成了提前设计好的部分，而不是事后打的补丁。

A read-only web preview of the mini-program, with sample data.小程序的只读网页预览，使用示例数据。

      

      Open in a new tab在新标签页打开
    

    
  • Full-stack mini-program that tracks subscriptions and memberships and reminds you before you're billed.全栈微信小程序，记录各种订阅和会员，在扣费前提醒你。
  • Serverless backend on WeChat Cloud: cloud functions, per-user data isolation and a daily job that scans for upcoming renewals.基于微信云开发的无服务器后端：云函数、按用户隔离数据，每天定时扫描即将到期的订阅。
  • Shared households: join with an invite code, and every member is notified before a shared subscription renews.共享组：凭邀请码加入，共享订阅到期前通知所有成员。

    
Why I made it为什么做
I kept forgetting to cancel free trials before they turned into charges.我老是忘了在免费试用变成扣费之前取消。
Hardest part最难的地方
WeChat only lets a mini-program send one reminder per user permission. I designed a flow that asks again at the right moment instead of treating it as a bug.微信每获得一次授权只能发一条订阅消息。我设计了在合适时机重新请求授权的流程，而不是把它当成无解的 bug。
What I learned学到了什么
Platform limits are design constraints. Working with them gave a better product than fighting them.平台限制本身就是设计约束，顺着它做出来的产品，比硬碰硬更好用。
